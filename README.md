# OOP-Project



## MacTrack

*Nutritional Tracker App*

The app will have several functions including:

*1. Meal Prepping* - organize meals in advance and see the macros for the meal.

*2. Macro Tracking* - Have the ability to log what you eat and track calories.

*3. TDEE Calculator* - Allows the usr to calculate their total daily expenditure, which allows them to see how many calories they need to eat to maintain, bulk, or cut.

*4. Food Info Tracker* - Look up nutritonal values for items, we will leverage the USDA FoodData API to get accurate information across many items
